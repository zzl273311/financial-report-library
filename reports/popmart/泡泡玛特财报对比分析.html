1.2 业务模式

公司以 IP 运营与孵化 为核心，构建了"艺术家 IP 发掘 → 产品设计开发 → 全渠道零售 → 会员运营 → IP 生态延伸"的闭环：

  • IP 两端：一端为艺术家 IP（自有，如 THE MONSTERS、MOLLY、SKULLPANDA、CRYBABY、DIMOO、星星人、HIRONO），另一端为授权 IP（与动漫、游戏、电影及明星艺人等版权方合作）。
  • 产品形态：毛绒玩具、手办、MEGA（大尺寸收藏品）及衍生品等。
  • 渠道结构：线下（零售店、机器人商店）+ 线上（自研 APP 及官网、泡泡玛特抽盒机、天猫旗舰店、抖音平台、TikTok 等）+ 批发及其他。
  • 地理结构：中国（含内地与港澳台）、亚太、美洲、欧洲及其他四大区域。
  • 生态延伸：泡泡玛特城市乐园（POP LAND）、IP 体验与创新业务孵化。

  1. 本报告全部数据取自公司在 香港交易所披露的定期报告与业绩公告原文，并经 pdftotext -layout 抽取核对（文件清单见附录）。

  6. 表格的列一律按时间递增排列，并分"年度块 → 半年度块"两块：先列年度（…2024、2025），再列半年度对照（2025H1 → 2026H1，即"上年同期 → 本期"），两块分界处以竖线标出。不作"本期 | 上年同期"的倒序排列——倒序会让读者先看到 2026H1 再退回 2025H1，时间轴断裂。跨块不可直接相减（年度流量与半年度流量口径不同）；本报告跨期比较以 2021—2025 年为主线，2020 年作为上市当年基期参考。

3.4 三表联动：一句话概括

  • 损益表看"经营真相"：2025 年是 IP 集中度与毛利率双高的极值年；2026H1 才是真实常态——收入 +23.8%、归母 +10.1%，利润率因海外占比回落与一次性损失而首次收缩。
  • 财务状况表看"资产质量"：资产端快速膨胀但质量分化——现金是无风险的（无借款、无抵押），存货是带风险的（周转天数 +78 天）。
  • 现金流量表看"现金去向"：经营端依然强劲，但现金已从"堆在账上"转向"分给股东"，2026H1 融资净流出首次超过经营净流入的一半。

  1. 2025 年的风险是真实的：单一 IP 贡献 38.1% 收入，且与"毛绒品类占 50.4%"高度重合（LABUBU 毛绒是主要载体），IP 风险与品类风险叠加，构成市场在 2025 年业绩发布后股价单日大跌 22.51% 的基本面基础。
  2. 2026H1 的改善也是真实的：THE MONSTERS 占比降至 26.0%（同比 34.7%），星星人从 2.8% 跃升至 15.4%、同比 +580.6%，成为第二大 IP；6 大 IP 收入破 10 亿、11 个 IP 过亿。管理层在电话会中称"整个 IP 的分布是非常健康的"。
须同时提示的反面：THE MONSTERS 绝对值出现首次同比负增长（4,814,017 → 4,454,361，−7.5%）。头部 IP 下滑而收入仍增长，靠的是第二梯队的承接——这既是多元化成功的证明，也意味着若星星人无法维持 580% 的增速，收入增速将进一步下台阶。

4.4 品类结构：一场"毛绒革命"

毛绒品类收入占比：21.7%（2024）→ 50.4%（2025）→ 57.2%（2026H1），两年从配角变主角。同期：

  • 手办占比 53.2% → 32.4% → 30.2%，2026H1 绝对值几乎零增长（5,175,875 → 5,192,493，+0.3%）；
  • 2025 年毛绒收入 187.08 亿元，同比 +560.6%。

手办"零增长"是 2026H1 报告中一个被低估的信号：手办是泡泡玛特最早的品类，也是中国内地线下门店的核心 SKU。其增长停滞意味着增长动能已完全依赖毛绒这一单一形态，与 IP 集中度问题形成同构风险。

五、关键内容总结

5.1 核心业务与竞争优势

  1. IP 平台化能力：艺术家 IP 收入占比 90.0%（2025），自主产品占 99.3%（2026H1）。公司具备把艺术家个人创作转化为可规模化商品的完整基建。
  2. 全渠道与会员资产：全球 676 家门店 + 2,827 台机器人商店（2026H1）；中国内地累计注册会员 8,244 万人、会员贡献销售 92.9%、复购率 51.6%。
  3. 全球化运营网络：已覆盖中国、亚太、美洲、欧洲四大区域，2025 年海外收入占比一度达 43.8%。
  4. 财务结构极健康：无银行借款、无资产抵押，2025 年末现金及现金等价物 137.75 亿元；资产负债率 29.4%（2026H1 降至 24.9%）。
  5. IP 生态延伸：泡泡玛特城市乐园（POP LAND）、IP 体验创新业务。

5.2 IP 与产品里程碑

  • THE MONSTERS（LABUBU）：2025 年收入 141.61 亿元（+365.7%），首次跻身百亿俱乐部，成为世界级 IP；2026 年 4 月推出 THE MONSTERS × FIFA 联名系列；2026H1 收入 44.54 亿元（−7.5%），占比由 34.7% 回落至 26.0%。

  • 六大 IP 破 10 亿 / 十一个 IP 过亿（2026H1）：THE MONSTERS、星星人、CRYBABY、DIMOO、SKULLPANDA、HIRONO。
  • 品类里程碑：毛绒玩具 2025 年首次成为收入贡献最高的品类（50.4%），2026H1 进一步升至 57.2%；Nyota、Zsiga、Peach Riot 等新 IP 推出首款毛绒产品。
  • FIFA 联名、CRYBABY「Cry Me An Ocean」新加坡海洋生态馆活动、SKULLPANDA × 小马宝莉联名等全球营销落地。

六、结论

一句话概括：泡泡玛特 2025 年交出了一份由单一 IP（LABUBU）与单一品类（毛绒）双轮驱动的历史最佳财报，2026 年上半年则进入"高基数下的常态化与结构修正期"——收入增速回落至 23.8%、归母增速回落至 10.1%，但同时 IP 集中度显著改善、中国内地重新成为引擎、股东回报大幅加码。

五个可验证的判断：

  1. 2025 年的极值不可外推，2026H1 才是估值的新基准。收入 +184.7%／归母 +308.8% 的增速由 LABUBU 现象级破圈一次性打开；2026H1 的 +23.8%／+10.1% 更接近常态化水平，且管理层已公开承认完不成 20% 增长目标。
  1. IP 多元化是真的在发生，且是本报告最正面的发现。THE MONSTERS 占比 38.1% → 26.0%、绝对值首次同比 −7.5% 的同时，星星人 +580.6% 至 15.4%、六大 IP 破 10 亿。头部 IP 下滑而公司收入仍增长，是多元化成功的最硬证据。
  1. 海外从"引擎"变"拖累"的性质需要区分对待。线上渠道全线下滑 40%—59% 而线下渠道全部正增长 16%—50%，说明这是渠道结构再平衡（2025 年门店不足导致流量畸高集中于线上），而非需求消失。但海外占比从 43.8% 降至 29.0% 对毛利率的拖累是真实且已被公司确认会延续至下半年。
  1. 存货是当前报表中最需要跟踪的单一风险指标。周转天数 123 → 201 天、余额两年增 575%、同时贸易应付款从 18.58 亿降至 9.05 亿——"备货 + 付货款"双击已使 2026H1 现金及等价物下降 13.33 亿元。若海外需求未如期恢复，减值或降价压力将先于利润表体现。
  1. 财务底盘依然极为扎实，是下行周期中的安全垫。无银行借款、无资产抵押，2025 年末现金及现金等价物 137.75 亿元（另有定期存款 34.50 亿元）；同期已经开始大规模反哺股东——2025 年度派息 31.94 亿元（分红率 25.0%）＋2026 年累计回购约 17.44 亿港元＋新宣布 20—50 亿元回购计划。

需要补充观察的下一个验证点：2026 年全年收入能否守住 20% 增速线；海外线上渠道在下半年是否止跌；存货周转天数是否随海外备货消化而回落至 150 天以内。
